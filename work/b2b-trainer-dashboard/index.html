Project context

The product needed an admin experience that could support enterprise-scale requirements, enable faster feature development, improve usability without breaking familiar user flows, and align with the long-term product roadmap.

The legacy dashboard functioned reliably but lacked scalability for growing enterprise demands.

Key issues

  • Increasing difficulty in adding new features
  • Framework limitations slowing development
  • UI/UX inconsistencies causing user friction
  • Navigation inefficiencies for admins and trainers
A complete architectural and UX revamp became necessary to ensure long-term sustainability.
***********

Stakeholder alignment

Trainers, managers, and leadership needed a dashboard that could keep pace with enterprise clients without forcing a disruptive relearn.

My role covered end-to-end ownership from research to release:

  • Built a custom design system on Ant Design
  • Shipped 15+ new features
  • Introduced AI-driven UX enhancements
  • Designed new analytics and reporting modules
  • Conducted user research and stakeholder interviews

The shared mandate: modernize the stack and UX while protecting the workflows admins already trusted.

***********

Research

We ran a research-driven redesign, analyzing:

  • Client support tickets
  • Admin and trainer interviews
  • Behavioral insights from Microsoft Clarity and PostHog

That work surfaced recurring UI/UX pain points, navigation friction, areas of repeated confusion, and workflow inefficiencies.

Insights were translated into system-level improvements rather than cosmetic changes — so the redesign could support faster shipping for years, not just a visual refresh.

***********

Content & IA

Navigation for admins and trainers was a primary friction point. We restructured information architecture so enterprise operations scaled without burying common tasks.

  1. Quarter 1 — Revamp the core dashboard for enterprise-scale ops
  2. Quarter 2 — Complete UX redesign across remaining screens
  3. Keep familiar mental models intact while cleaning inconsistent patterns

The IA was built to absorb new analytics, reporting, and AI-assisted flows without another structural rewrite.

***********

Key page designs

Admin operations hub

The redesigned dashboard gave trainers and managers a clearer home for day-to-day training operations — with hierarchy and density suited to enterprise use.

Analytics & reporting

New analytics and reporting modules were designed as first-class surfaces — not bolted-on tables — so managers could act on training performance without leaving the admin experience.

AI-driven enhancements

AI-assisted UX patterns were introduced where they reduced repetitive admin work, without interrupting the flows trainers already knew.

***********

Conversion & UX

Usability had to improve without breaking familiar flows — especially for power users who lived in the dashboard daily.

  1. Reduce navigation inefficiency for admins and trainers
  2. Resolve UI inconsistencies that caused repeated confusion
  3. Preserve known workflows while enabling faster feature adoption
Improve usability without breaking familiar user flows — and still unlock enterprise-scale growth.
***********

Handoff

We transitioned from Ember.js to React.js, implementing a scalable design system built on Ant Design.

Ant Design was selected for strong enterprise adoption, comprehensive documentation, and a large developer community. Light CSS enhancements were applied to core primitives to create a flexible system ready for rapid shipping.

  • Shared components and spacing rules for the new React stack
  • Documentation so engineering could extend features without redesigning basics
  • Handoff oriented around sustainable velocity, not a one-time visual pass
***********

Impact

The impact was significant — sales increased by 40%, and we acquired industry-leading enterprise clients within their domains, directly driving higher product revenue.

  1. 40% increase in sales after the dashboard modernization
  2. 10+ industry-leading clients won in their respective domains
  3. Faster feature velocity on a React + Ant Design system built for enterprise scale
The dashboard stopped being a legacy bottleneck — and became a platform that could keep shipping.
